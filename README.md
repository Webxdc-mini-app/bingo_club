# BINGO CLUB

Delta Chatのグループで遊ぶ、パーティ用ビンゴのwebxdcミニアプリです。司会者の抽選端末1台と、参加者のカード端末複数台で使います。

[アプリをダウンロード](party-bingo.xdc) · [HTMLマニュアル](BINGO_CLUB_操作マニュアル.html) · [PDFマニュアル](BINGO_CLUB_操作マニュアル.pdf) · [Wordマニュアル](BINGO_CLUB_操作マニュアル.docx)

## 主な機能

- 参加者のリクエストを受け、抽選端末からカードを自動配布
- 1～75の数字を重複なしで抽選し、グループ内で結果を共有
- 当たった数字を自動マークし、リーチ・ビンゴとライン数を表示
- 参加メンバーのカード配布状況と当選状況を一覧表示
- 共有履歴の読み込みによる途中参加・再開
- カード受け取り、抽選、当たり、リーチ、ビンゴなどの効果音
- 端末ごとの効果音オン・オフ、音量調整、試聴
- ブラウザー内だけで体験できるデモ

外部ライブラリーや外部通信は使用しません。共有にはDelta Chatが提供するwebxdcの更新APIを使い、効果音は端末内で合成します。

## Delta Chatでの使い方

1. 主催者が `party-bingo.xdc` をグループチャットにファイルとして送ります。
2. 全員が、**同じ投稿のアプリ**を開きます。
3. 司会者1人だけが「抽選端末にする」を押します。
4. 参加者はニックネームを入力し、「カード端末で参加 →」を押します。
5. 司会者はアプリを開いたままにして、全員にカードが届いたことを確認します。
6. 司会者が「次のナンバーを抽選 ✦」を押し、参加者への反映を待ちながら進めます。
7. ビンゴが表示された参加者は司会者に知らせます。司会者は「参加メンバー」でも確認できます。

司会者もカードで遊ぶ場合は、「マイカード」の「カードを受け取る」を押してください。

通信状況や送信間隔によって反映に時間がかかります。抽選ボタンを連打せず、参加者の表示を確認して進めてください。「グループで共有」の表示は、全員の受信完了を示すものではありません。

### 効果音

最初は消音です。各端末で画面上部の「♪ 音をオン」を押してください。

- 音量スライダーで音量を調整します。
- 「試聴」は音をオンにしてビンゴの音を再生します。
- 「♪ 音：オン」を押すと消音します。
- 設定は端末ごとに保存されます。再度開いて「音を有効化」と表示された場合は、そのボタンを押してください。
- 履歴の初回読み込み中や、画面が非表示の間は音を鳴らしません。
- 複数の条件を同時に満たした場合は、ビンゴなどを優先して1種類だけ鳴らします。

音が出ない場合は、端末のメディア音量・消音設定を確認してください。音声機能を利用できない端末でも、ゲームは画面で進められます。

### 次のゲームを始める

`party-bingo.xdc` をグループに**新しい投稿として再送信**し、全員がその新しい投稿を開きます。古い投稿を開き直しても、新しいゲームにはなりません。更新版に切り替える場合も、新しい投稿から始めてください。

## ビンゴのルール

5×5のカードで、中央は最初から当たりのFREEです。縦5本、横5本、斜め2本のいずれかがそろうとビンゴです。

| 列 | 数字の範囲 |
| --- | --- |
| B | 1～15 |
| I | 16～30 |
| N | 31～45（中央はFREE） |
| G | 46～60 |
| O | 61～75 |

75球すべてを抽選すると抽選は終了します。景品や順位は主催者が決めます。

## 現在の制限

- 抽選端末は1台を選び、ゲーム中は同じ端末で進めてください。同時に複数人が設定しないでください。
- 司会者の交代、途中のカード再発行、同じ投稿内でのリセットには対応していません。
- カードは端末のローカル保存領域の識別子にひも付きます。同じアカウントでも別端末では別カードになります。
- ゲーム中に保存データを消したり、別端末に切り替えたりしないでください。
- カード情報はグループ全員に共有され、秘密の配布ではありません。
- 役割の制御はアプリ内の運用上の仕組みです。改造クライアントへの対策や本人認証は備えていません。
